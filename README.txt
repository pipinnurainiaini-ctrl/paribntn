VERSI NETLIFY DENGAN DATABASE DUMMY

Data destinasi dibaca dari wisata.json melalui fetch().
Favorit, keranjang dan pesanan simulasi disimpan di localStorage pada browser masing-masing.
Harga hanya contoh simulasi, bukan harga tiket resmi.
Tidak ada database online, login asli, pembayaran, admin, atau e-ticket QR terverifikasi.
Upload isi folder ini (index.html berada di root) ke Netlify Drop.
Jangan buka HTML langsung lewat file:// karena fetch JSON dapat gagal.
